# SCOOPROVO GitHub Pages 업로드 파일

이 폴더 안의 파일 전체와 assets 폴더를 GitHub 저장소 첫 화면에 업로드하세요.
이 폴더 자체나 ZIP 파일을 올리는 것이 아니라, 압축을 푼 뒤 안의 내용물을 올립니다.
index.html과 assets 폴더가 저장소 최상위에서 보여야 합니다.

## 업로드 순서
1. https://github.com/hyephyel-max/scooprovo 에 접속합니다.
2. Add file → Upload files를 누릅니다.
3. 이 폴더 안의 파일 전체와 assets 폴더를 드래그합니다.
4. Commit changes를 누릅니다.
5. Settings → Pages를 엽니다.
6. Source는 Deploy from a branch, Branch는 main, Folder는 / (root)로 설정하고 Save를 누릅니다.
7. 배포가 완료되면 Visit site로 접속합니다.
예상 주소: https://hyephyel-max.github.io/scooprovo/

## 포함 내용
- index.html: 웹사이트 시작 화면
- CSS 파일: 디자인
- JS 파일: 메뉴 선택·컵 합성·로봇 표정 전환·공유 등
- assets/: 이미지
- .nojekyll: 정적 웹사이트 게시용 숨김 파일
- README.md: 이 안내문

파일명과 assets 폴더 구조는 바꾸지 마세요.
별도의 설치·빌드 명령 없이 게시할 수 있는 정적 웹 파일입니다.
기존 웹의 디자인과 기능을 변경하지 않고 복사했습니다.

## 확인 사항
- GA4 측정 ID는 아직 설정되지 않았습니다. settings.js의 ga4MeasurementId에 실제 G-... ID를 연결해야 전체 방문자·클릭 데이터를 수집합니다.
- 결제·이름 응모·재고는 프로토타입 체험입니다. 실제 거래나 서버 접수는 하지 않습니다.
- 이미지를 저장해 공유하거나 지원 기기의 공유창을 여는 방식이며, SNS에 자동 게시하지 않습니다.
- 이름·체험 잔액 등 브라우저 저장 정보는 기존 공개 주소와 새 GitHub 주소 사이에 이전되지 않습니다.
